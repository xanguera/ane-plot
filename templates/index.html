About Phonetic Neighbors

This web application visualizes the phonetic/acoustic similarity between words as an interactive 2D edge-weighted graph, an acoustic network embedding (ANE) visualization.

Key Components:

  • Acoustic Embeddings: Utilizes Woojay Jeon's (@Apple) Acoustic Neighbor Embeddings (ACN) to map words into a high-dimensional space where similar-sounding words are closer together. There is a setting at the top of the page for the dimensionality of the global embedding.
  • Radial Layout: The query word sits in the centre and each neighbor sits at its true embedding distance from it, so the length of each query link is to scale. The direction of each neighbor comes from a PCA projection, which keeps similar-sounding neighbors on the same side. Links between two neighbors (Full graph) are only approximate.
  • Interactive Graph: Renders query words and their nearest acoustic neighbors using D3.js. Hover over nodes to inspect individual similarity distances.

By Kent Slaney and Malcolm Slaney with an implementation by Antigravity. For more details see this CCRMA blog post. The source code is available on GitHub.
